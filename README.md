# AI Video Learning Platform

A social media AI-integrated learning platform MVP built with Next.js. It combines creator publishing, video analysis, and a learning feed.

## Features
- AI-powered video analysis workflow
- Social learning feed
- Creator upload & publishing dashboard
- Structured lesson generation from video content
- Smart highlight extraction and chapter suggestions

## Tech Stack
- Next.js 14
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Notes
This MVP includes a mock AI analysis API so the app can run without external API keys. Replace the mock logic with real transcription and summarization providers in production.
